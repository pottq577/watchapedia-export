# WatchaPedia Ratings Exporter

[왓챠피디아](https://pedia.watcha.com/ko)에서 내가 평가한 **영화·시리즈 기록을 CSV로 백업하고, 이후 변경분만 반영해 갱신**하는 비공식 Tampermonkey userscript입니다.

Chrome 환경에서의 사용을 기준으로 안내합니다.

## 사용법

### 방법 1: Tampermonkey 활용

1. 브라우저에 [Tampermonkey](https://www.tampermonkey.net/)를 설치합니다.
2. `chrome://extensions/`에서 **Tampermonkey → 세부정보 → 사용자 스크립트 허용**을 활성화합니다.
   - 이 옵션이 꺼져 있으면 userscript가 설치되어 있어도 왓챠피디아 페이지에서 실행되지 않을 수 있습니다.
3. 이 저장소의 `watchapedia-exporter.user.js` [Raw 파일](https://github.com/pottq577/watchapedia-export/raw/refs/heads/main/watchapedia-exporter.user.js)을 엽니다.
4. Tampermonkey 설치 화면에서 userscript를 설치합니다.
5. `https://pedia.watcha.com/ko`에 로그인한 상태로 접속합니다.
6. 화면 오른쪽 아래의 **WP Export** 버튼을 누릅니다.

> **`WP Export` 버튼이 보이지 않는 경우**  
> Tampermonkey의 **사용자 스크립트 허용** 옵션을 확인한 뒤 왓챠피디아 페이지를 새로고침하세요.

### 방법 2: DevTools Console에서 직접 실행

Tampermonkey를 설치하지 않고 일회성으로 실행할 수도 있습니다.

1. `https://pedia.watcha.com/ko`에 로그인한 상태로 접속합니다.
2. `watchapedia-exporter.user.js` [Raw 파일](https://github.com/pottq577/watchapedia-export/raw/refs/heads/main/watchapedia-exporter.user.js)을 엽니다.
3. 파일 전체 내용을 복사합니다.
4. 브라우저 개발자 도구의 **Console** 탭으로 이동합니다.
   - Chrome / Edge: `F12` 또는 `Ctrl + Shift + J`
   - macOS: `Cmd + Option + J`
5. 복사한 코드를 붙여넣어 실행합니다.
6. 화면 오른쪽 아래의 **WP Export** 버튼을 누릅니다.

DevTools에서 실행한 스크립트는 페이지를 새로고침하거나 다른 페이지로 이동하면 사라질 수 있습니다. 반복 사용은 Tampermonkey 방식을 권장합니다.

> Chrome 등 일부 브라우저에서는 Console에 코드를 처음 붙여넣을 때 붙여넣기가 차단될 수 있습니다. 개발자 도구의 안내에 따라 직접 붙여넣기를 허용한 뒤 다시 실행하세요.

## 최초 백업

1. **WP Export** 클릭
2. **새 백업 만들기** 클릭
3. 평가 목록과 장르·국가 정보 수집이 끝날 때까지 대기
4. 자동 다운로드된 CSV 보관

> 요청 제한을 피하기 위해 데이터를 일정 간격으로 순차 조회합니다. **평가한 작품이 많을수록 최초 백업에 시간이 오래 걸릴 수 있습니다.**  
> 수집 중 탭을 닫거나 페이지를 새로고침해도 완료된 진행 상태는 브라우저 IndexedDB에 임시 저장되며, 다음 실행에서 **중단된 작업 이어서 진행**으로 재개할 수 있습니다.

## 이후 업데이트

1. **WP Export** 클릭
2. **기존 백업 업데이트** 클릭
3. 이전에 저장한 CSV 선택
4. 현재 왓챠피디아 평가와 비교
5. 신규·변경·삭제 항목을 반영한 새 CSV 자동 다운로드

업데이트 시 `content_code`를 기준으로 비교합니다.

- 기존 작품: 현재 제목·연도·평점으로 갱신
- 평점 변경: 현재 값으로 반영
- 신규 평가: 새 행 추가 후 장르·국가 조회
- 평가 취소: 새 CSV에서 제거
- 기존 장르·국가: 재사용
- 기존 CSV에서 장르·국가가 비어 있는 작품: 상세 정보를 다시 조회

기존 CSV는 수정하지 않습니다. 새로 내려받은 CSV가 다음 업데이트의 기준 파일이 됩니다.

## CSV 형식

| type  | title  | year | rating | genres               | countries | content_code |
| ----- | ------ | ---- | ------ | -------------------- | --------- | ------------ |
| movie | 옵세션 | 2025 | 5      | 공포\|스릴러\|로맨스 | 미국      | m5mYj6B      |

수집 항목은 다음과 같습니다.

- 콘텐츠 유형 (`movie`, `series`)
- 제목
- 연도
- 내 평점
- 장르
- 국가
- `content_code`

다중 장르·국가는 `|` 문자로 구분합니다.

## 수집 중 종료 및 재개

수집 도중 탭을 닫거나 페이지를 새로고침하면 진행 상태를 브라우저 IndexedDB에서 복구합니다.

- 평가 목록은 마지막으로 완료된 페이지 다음부터 이어집니다.
- 작품 상세 정보는 성공한 항목을 다시 요청하지 않습니다.
- 네트워크 오류 등으로 실패한 상세 정보만 다음 재개 시 다시 시도합니다.
- 상세 정보 일부가 최종 재시도까지 실패하면 CSV를 완료 처리하지 않고 체크포인트를 유지합니다.
- 장르 또는 국가가 실제 페이지에서 비어 있는 경우에는 실패가 아니라 누락 경고로 처리할 수 있습니다.
- CSV가 정상 다운로드되면 임시 체크포인트는 자동 삭제됩니다.
- userscript 업데이트로 체크포인트 저장 형식이 호환되지 않으면 기존 작업은 재개하지 않습니다. 새 작업을 시작하면 기존 임시 데이터를 삭제할 수 있습니다.

브라우저에서 왓챠피디아 사이트 데이터를 직접 삭제하면 임시 진행 상태도 사라질 수 있습니다.

## 동작 범위

현재 지원 범위:

- 영화 평가
- 시리즈 평가
- 최초 전체 백업
- 기존 CSV 기반 증분 업데이트
- 중단 작업 재개

`책`, `웹툰`, `코멘트`, `보고싶어요` 등은 수집하지 않습니다.

## 개인정보 및 인증 정보

이 userscript는 현재 브라우저의 왓챠피디아 로그인 세션 안에서 실행됩니다.

- 비밀번호 입력을 요구하지 않습니다.
- 세션 쿠키나 인증 토큰을 외부 서버로 전송하지 않습니다.
- 수집 결과는 브라우저에서 CSV로 생성됩니다.
- 외부 서버나 외부 데이터베이스에 수집 결과를 저장하지 않습니다.
- 중단 복구를 위한 평가 목록과 진행 상태만 현재 브라우저의 IndexedDB에 임시 저장합니다.
- 상세 페이지 원본 HTML은 IndexedDB에 저장하지 않습니다.

## 주의사항

이 프로젝트는 왓챠 또는 왓챠피디아의 공식 도구가 아닙니다.

왓챠피디아의 내부 API나 HTML 구조가 변경되면 동작하지 않을 수 있습니다. 또한 왓챠피디아 페이지에는 사전 동의 없는 크롤링 및 데이터 수집을 금지한다는 안내가 표시되어 있으므로, 사용 전 현재 서비스 약관과 정책을 직접 확인하고 본인의 데이터 백업 목적에 맞게 사용하세요.

과도한 요청을 피하기 위해 평가 API와 상세 페이지는 일정 간격을 두고 순차적으로 요청하며, `429` 또는 일시적인 서버 오류가 발생하면 지수 백오프로 재시도합니다.

## 버그 제보

동작 오류나 왓챠피디아 HTML 구조 변경으로 장르·국가 등이 정상 수집되지 않는 경우 [GitHub Issues](https://github.com/pottq577/watchapedia-export/issues/new/choose)에서 제보할 수 있습니다.

- 일반 실행 오류: **버그 제보** 템플릿
- 장르·국가 누락 등 구조 변경 의심: **HTML 구조 변경 제보** 템플릿
- 가능하면 userscript 버전, 브라우저/Tampermonkey 버전, 재현 절차, 콘텐츠 URL, Console 오류 메시지를 함께 작성해 주세요.
- 세션 쿠키, 인증 토큰, 개인 식별 정보가 포함된 요청 헤더나 로그인 상태의 전체 HTML은 첨부하지 마세요.
