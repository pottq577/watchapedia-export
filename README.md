# WatchaPedia Ratings Exporter

[왓챠피디아](https://pedia.watcha.com/ko)에서 내가 평가한 **영화·시리즈 기록을 CSV로 백업하고, 이후 변경분만 반영해 갱신**하는 비공식 Tampermonkey userscript입니다.
이 저장소는 브라우저가 Chrome 환경일 때 최적으로 동작합니다.

## 사용법

### 방법 1: Tampermonkey 활용

1. 브라우저에 [Tampermonkey](https://www.tampermonkey.net/)를 설치합니다.
2. 브라우저의 [확장 프로그램 관리 화면](chrome://extensions/)에서 Tampermonkey → 세부정보 → 사용자 스크립트 허용을 활성화합니다.
   1. 이 옵션이 꺼져 있으면 `userscript`가 설치되어 있어도 왓챠피디아 페이지에서 실행되지 않을 수 있습니다.
3. 이 저장소의 `watchapedia-exporter.user.js` [Raw 파일](https://github.com/pottq577/watchapedia-export/raw/refs/heads/main/watchapedia-exporter.user.js)을 엽니다.
4. Tampermonkey의 설치 화면에서 userscript를 설치합니다.
5. `https://pedia.watcha.com/ko/`에 로그인한 상태로 접속합니다.
6. 화면 오른쪽 아래의 **WP Export** 버튼을 누릅니다.

> `WP Export` 버튼이 보이지 않는 경우
> 먼저 Tampermonkey 확장 프로그램의 **사용자 스크립트 허용** 옵션이 켜져 있는지 확인한 뒤 왓챠피디아 페이지를 새로고침하세요.

### 방법 2: 브라우저 개발자 도구(DevTools) Console에서 직접 실행

1. `https://pedia.watcha.com/ko/`에 로그인한 상태로 접속합니다.
2. 이 저장소의 `watchapedia-exporter.user.js` [Raw 파일](https://github.com/pottq577/watchapedia-export/raw/refs/heads/main/watchapedia-exporter.user.js)을 엽니다.
3. 파일 전체 내용을 복사합니다.
4. 왓챠피디아 페이지에서 브라우저 개발자 도구를 열고 **Console** 탭으로 이동합니다.
   - Chrome / Edge: `F12` 또는 `Ctrl + Shift + J`
   - macOS: `Cmd + Option + J`
5. 복사한 코드를 Console에 붙여넣고 실행합니다.
6. 화면 오른쪽 아래에 나타난 **WP Export** 버튼을 눌러 사용합니다.

DevTools에서 실행한 경우 페이지를 새로고침하거나 다른 페이지로 이동하면 스크립트가 사라질 수 있으므로 다시 실행해야 합니다. 반복해서 사용할 경우에는 Tampermonkey 설치 방식을 권장합니다.

> Chrome 등 일부 브라우저에서는 보안을 위해 Console에 코드를 처음 붙여넣을 때 붙여넣기가 차단될 수 있습니다. 이 경우 개발자 도구에 표시되는 안내에 따라 직접 붙여넣기를 허용한 후 다시 실행합니다.

### 최초 사용

1. **WP Export** 클릭
2. **새 백업 만들기** 클릭
3. 평가 목록과 상세 메타데이터 수집이 끝나면 CSV가 자동 다운로드됨
4. 내려받은 CSV를 보관

### 이후 업데이트

1. **WP Export** 클릭
2. **기존 백업 업데이트** 클릭
3. 이전에 저장한 CSV 선택
4. 현재 왓챠피디아 평가와 비교
5. 신규/변경/삭제 항목을 반영한 새 CSV가 자동 다운로드됨

CSV 파일 자체가 다음 업데이트의 체크포인트 역할을 합니다.
별도 DB, 서버, 계정 연동은 사용하지 않습니다.

## 기능

### 새 백업 만들기

현재 로그인한 왓챠피디아 계정의 영화·시리즈 평가를 수집하고 각 작품의 장르·국가 정보를 보강해 CSV로 저장합니다.

CSV 데이터 예시:

| type  | title  | year | rating | genres                | countries | content_code |
| ----- | ------ | ---- | ------ | --------------------- | --------- | ------------ |
| movie | 옵세션 | 2025 | 5      | 공포\|스릴러\| 로맨스 | 미국      | m5mYj6B      |

`content_code`를 작품의 고유 키로 사용합니다.

### 기존 백업 업데이트

이전에 저장한 CSV를 선택하면 현재 평가 목록과 `content_code` 기준으로 비교합니다.

- 기존 작품: 현재 제목·연도·평점으로 갱신
- 평점 변경: 현재 값으로 반영
- 신규 평가: 새 행 추가 후 장르·국가 조회
- 평가 취소: 새 CSV에서 제거
- 기존 장르·국가: 그대로 재사용
- 기존 CSV에서 장르·국가가 비어 있는 작품: 다시 상세 조회

따라서 업데이트 시 전체 작품 상세 페이지를 다시 조회하지 않고 **신규 또는 메타데이터가 누락된 작품만** 상세 정보를 요청합니다.

기존 CSV는 수정하지 않으며 결과는 날짜가 포함된 새 파일로 다운로드됩니다.

## 데이터 처리 방식

평가 목록은 현재 로그인한 브라우저 세션에서 왓챠피디아가 사용하는 평가 API를 순차 조회합니다.

평가 목록에서 다음 값을 수집합니다.

- 콘텐츠 유형 (`movie`, `series`)
- 제목
- 연도
- 내 평점
- `content_code`

장르·국가는 각 작품의 공개 상세 페이지 HTML에서 읽습니다.
다중 장르·국가는 `|` 문자로 구분해 한 셀에 저장합니다.

업데이트 시 평가 목록은 현재 상태를 다시 읽지만, 상세 페이지 조회는 신규/누락 작품으로 제한합니다.

## 동작 범위

현재 버전은 다음 항목만 지원합니다.

- 영화 평가
- 시리즈 평가
- 최초 전체 백업
- 기존 CSV 기반 증분 업데이트

`책`, `웹툰`, `코멘트`, `보고싶어요` 등의 데이터는 수집하지 않습니다.

## 개인정보 및 인증 정보

이 userscript는 현재 브라우저의 왓챠피디아 로그인 세션 안에서 실행됩니다.

- 비밀번호 입력을 요구하지 않습니다.
- 세션 쿠키나 인증 토큰을 외부 서버로 전송하지 않습니다.
- 수집 결과는 사용자의 브라우저에서 CSV 파일로 생성됩니다.
- 별도의 서버나 데이터베이스를 사용하지 않습니다.

## 주의사항

이 프로젝트는 왓챠 또는 왓챠피디아의 공식 도구가 아닙니다.

왓챠피디아의 내부 API와 HTML 구조가 변경되면 동작하지 않을 수 있습니다.
또한 왓챠피디아 페이지에는 사전 동의 없는 크롤링 및 데이터 수집을 금지한다는 안내가 표시되어 있으므로, 사용 전 현재 서비스 약관과 정책을 직접 확인하고 본인의 데이터 백업 목적에 맞게 사용하세요.

과도한 요청을 피하기 위해 평가 API와 상세 페이지는 일정 간격을 두고 순차적으로 요청하며, `429` 또는 일시적인 서버 오류가 발생하면 지수 백오프로 재시도합니다.

## 개발

빌드 과정이나 외부 의존성이 없습니다.

userscript를 수정한 뒤 브라우저/Tampermonkey에서 다시 설치해 확인하면 됩니다.

간단한 JavaScript 문법 검사는 Node.js로 실행할 수 있습니다.

```bash
node --check watchapedia-exporter.user.js
```
