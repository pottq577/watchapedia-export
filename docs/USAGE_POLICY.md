# 사용 정책 및 주의사항

이 문서는 WatchaPedia Ratings Exporter의 사용 목적과 서비스 정책 관련 주의사항을 설명합니다.
소스 코드 사용권은 [`LICENSE`](../LICENSE)가 정하며, 왓챠피디아 서비스 이용에는 왓챠피디아의 이용약관과 정책이 별도로 적용됩니다.

## 프로젝트 목적

이 프로젝트는 개인이 자신의 왓챠피디아 영화·시리즈 평가 기록을 CSV로 백업하고 갱신하기 위해 만든 비공식 도구입니다.
수집 결과는 사용자의 브라우저에서 처리하며 프로젝트 운영자가 별도로 수집하거나 저장하지 않습니다.

이 프로젝트는 왓챠 또는 왓챠피디아와 제휴하거나 승인을 받은 공식 도구가 아닙니다.

## 왓챠피디아 서비스 정책

이 도구는 로그인된 사용자의 브라우저에서 왓챠피디아의 평가 목록과 작품 상세 정보를 자동으로 요청합니다.
왓챠피디아의 현재 이용약관은 회사와 다른 회원의 정보를 크롤링, 스크래핑, 수집, 추출, 복제 또는 복사하는 행위를 제한하고 있습니다.

서비스 약관과 정책은 변경될 수 있습니다.
실행 전에 [왓챠피디아 이용약관](https://watcha.com/ko-KR/legals/agreement)과 서비스 내 안내를 확인하세요.

도구를 실행하면 서비스 정책과 운영 기준에 따라 다음과 같은 제한이 발생할 수 있습니다:

- 요청 제한 또는 오류 응답
- 일시적 또는 지속적 접근 차단
- 계정 이용 제한 또는 정지
- 내부 API 또는 HTML 구조 변경에 따른 동작 중단
